# Contributing

Discuss substantive changes in an issue or pull request. Preserve the MIT license and third-party notices, never include private portfolio materials or credentials, and keep changes scoped and reviewable.

Use Node 24 and run the offline and integration tests described in [evaluation](docs/evaluation.md). The GitHub workflow also checks the release archive, PostgreSQL quota behavior and clean registry installations. Use fake providers for development and include tests for changed security or integration behavior. Real model calls, database migrations and deployments require separate authorization.
