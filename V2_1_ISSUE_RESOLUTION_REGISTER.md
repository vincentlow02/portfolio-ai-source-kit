### IA-16 — plural follow-up lost project scope

- **Classification / module:** Confirmed defect, P1; shared `resolveContext`, evidence assembly and Hosted excerpt path.
- **Code evidence / root cause:** Previously `isContextualFollowUp` did not recognise explicit plural project references, so `resolveContext` returned no projects and search could include all public projects. `dcca1b3`, `6523b85`, `b5e02fe`, `f9ec58e` and `036b31a` carry only recognised plural comparison references and apply a conservative body/clause topic check. Current code is at `lib/portfolio-chat/retrieval.ts:83` and `:129`, `lib/portfolio-chat/b2.ts:147`, and `lib/portfolio-chat/source-reply.ts:60`; the latter returns one cited excerpt per project or insufficient evidence for this case.
- **User impact / reproduction:** Run `scripts/portfolio-chat/plural-context-holdout.mts` with `PORTFOLIO_EVAL_ROOT` pointing to the pre-fix `16401f9` checkout and then the current checkout. After “Compare Alder and Birch”, ask “When were both projects tested?” Before the change the pack included the unrelated Elm project and the excerpt showed only Elm; after it, both expected project passages are returned. Synthetic fixture, no provider call.
- **Fix / regression risk:** Preserve the explicit plural scope and compare each project's evidence; keep singular, mixed and selection-of-one references conservative. The clause and word checks are heuristics, may accept unrelated same-clause facts, and may reject valid multi-sentence or cross-language support. Other plural phrasings are not covered.
- **Acceptance / evidence:** `hybrid-retrieval.test.mts` tests three languages, singular ambiguity, one-sided evidence and zero quota; `test-hosted-integration.mts` checks two actual Hosted citations and unsupported abstention. The independently frozen, same-reviewer 12-case synthetic holdout has 4/4 supported two-sided excerpts, 5/5 unsupported abstentions and 3/3 singular clarifications; it is too small to establish general correctness. A larger independently judged corpus and real-provider evaluation remain required.
