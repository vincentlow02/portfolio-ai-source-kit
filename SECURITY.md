# Reporting a vulnerability

Do not include credentials, private corpus contents or exploit details in a public issue. Use **Report a vulnerability** on the repository's [security advisories page](https://github.com/vincentlow02/portfolio-ai-source-kit/security/advisories) to send the maintainers a private report. If private reporting is unavailable, contact the repository owner privately through a channel they provide; do not assume a public issue is confidential.

See [security and deployment](docs/security.md) for the current operating boundaries. The maintainer has not made a response-time or support guarantee.
