# Security, configuration and deployment

Keep `.env.local`, Supabase server credentials, model API keys, generated corpora and build output out of Git and client bundles. The included example has placeholders only. The hosted widget does not persist questions or send analytics events.

On Vercel production, the hosted assistant can check model quota with a published `portfolio-ai-qwen` Firewall rule. The rule uses one shared bucket per region. Use a provider-side budget for spending across regions and account for the delay before Model Studio stops calls. The hosted assistant uses excerpts from the selected evidence when the limit is reached or either service is unavailable. [Hosted Qwen setup](../README.md#optional-qwen-on-the-hosted-assistant) · [Vercel Firewall SDK](https://vercel.com/docs/vercel-firewall/vercel-waf/rate-limiting-sdk) · [Model Studio budget management](https://www.alibabacloud.com/help/en/model-studio/budget-management)

The Next.js integration and hosted installations using Supabase use the existing shared quota migration for generation. Review the migration before applying it to a dedicated project. It enables row-level security, limits application grants and creates the quota function. The legacy database object names are retained for compatibility. The Next.js integration rejects configured-model requests if reservation fails. Set `PORTFOLIO_AI_ANALYTICS=1` to opt in to native session and event metadata. Those events omit raw questions and answers. `PORTFOLIO_AI_TIMING=1` independently logs numeric latency and token counts.

Set `PORTFOLIO_AI_QUOTA_PER_MINUTE`, `PORTFOLIO_AI_QUOTA_PER_DAY`, `PORTFOLIO_AI_DAILY_BUDGET_USD` and conservative input/output rates per million tokens. Use the highest rate applicable to the possible input tier. The reservation estimates 100,000 input and 700 output tokens per call; it is a conservative application control, not the provider's invoice or a substitute for a provider-side budget. Set provider spending controls and independently review your threat model.

Model quota and request/compute limits protect different resources. The Next and Hosted model paths reserve before calling the provider. Reservations are consumed even if the request is cancelled, times out or returns a provider or validation error. Guardian, clarification and insufficient-evidence paths return before model reservation. Local model preview is opt-in and does not use the shared model quota.

Hosted excerpt mode does not reserve model quota. Its 60-per-minute and two-active limits are per process; N replicas can collectively admit roughly N times those bounds, and CPU-intensive retrieval happens before any model reservation. For publicly exposed multi-instance deployments, configure an independently monitored distributed request/compute limit at the edge before enabling traffic. The existing Supabase deployment could host a separate atomic counter/RPC for this purpose, but the model reservation function is not an appropriate substitute: it charges model budget for non-model work and requires secrets even in excerpt mode. This kit does not provide a distributed excerpt counter, and origin headers are not a substitute. Measure real cold-start costs and choose limits for the deployment.

For Qwen, select a regional Model Studio pay-as-you-go endpoint matching your key. Set `PORTFOLIO_AI_PROVIDER=qwen`, `QWEN_API_KEY`, `QWEN_BASE_URL` and `QWEN_MODEL`. Use the base URL ending in `/compatible-mode/v1`. Start with `QWEN_JSON_MODE=object` for `qwen3.7-flash`. Use `schema` with a compatible provider endpoint. The server validates structured output in both modes. For OpenAI or AI Gateway set `PORTFOLIO_AI_PROVIDER=openai` or `gateway`, the corresponding `OPENAI_API_KEY` or `AI_GATEWAY_API_KEY`, and optionally `PORTFOLIO_AI_MODEL`. To use an alternative model in native public or protected Preview mode, include its `provider/model` in `allowedPublicModels` and configure the applicable provider prices and quota.

Local browser access requires the loopback-bound dev script and `PORTFOLIO_AI_LOCAL_DEV=1`. The server also supports an evaluation bearer token of at least 32 characters; never embed this token in a browser bundle. Public deployment is off unless `PORTFOLIO_AI_PUBLIC_ENABLED=1`, an exact HTTPS `PORTFOLIO_AI_PUBLIC_ORIGIN` is configured, and all other controls are satisfied. Origin checks are not user authentication and can be forged outside a browser. Review abuse controls and spending exposure before enabling public access.

For Vercel Preview, use an isolated project and enable platform Deployment Protection before enabling `PORTFOLIO_AI_PROTECTED_PREVIEW=1`. Verify unauthenticated requests to the actual preview URL and aliases are denied, then verify the deployed build and corpus match, origin validation, quotas and citations. Production and preview must not share unreviewed credentials or settings. Atlas adds basic response headers in its Next config; adapt and verify them in the host.
